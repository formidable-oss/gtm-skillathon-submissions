**How it works, in five lines**

1. Teams of one or two. You build one reusable agent skill that solves a real go-to-market problem with real-world web data. No coding required; a skill is a Markdown file your agent follows.
2. You build with any agent you like (Codex, Claude Code, Cursor, anything). The jury runs your work in the Codex desktop app from a single laptop.
3. You submit a public GitHub repository created from our template, plus a commit. Submissions are GitHub issues; anything filed after 20:30:00 is rejected automatically. No extensions.
4. The organizer presents every team in random order, 2 minutes each, from your repository alone. You do not present, so your repository has to speak for you.
5. Scoring: automated checks and five Codex-proposed scores from your repository, plus presentation and vibe from the jury. Full criteria are in the rules.

**Before you arrive — 5 minutes**

- A GitHub account, and git installed.
- Your agent of choice installed and signed in. Codex users: the desktop app or CLI; run `codex` once so it is ready.
- Node.js 18 or newer (`node --version`), used by the submission helper.
- Optional: the `gh` CLI, signed in (`gh auth login`). It lets your agent submit for you; without it you submit through a prefilled web form.
- One GTM problem you actually have. The more specific, the better.
